PATLING FIGHTERS — PIXEL EDITION
=================================

FULL SOURCE CODE: index.html (HTML + CSS + JavaScript in one file)

RUN IT:
1. Download and extract Patling_Fighters_Pixel.zip.
2. Open index.html in Chrome or Microsoft Edge.
3. Click START ROUND.
4. Use the keyboard controls below. On mobile, use the touch buttons.

PLAYER 1 — GABRIELA LISING
A/D = move, W = jump, Z = punch, X = Sleep Power, C = Full Breath Combo.

PLAYER 2 — MARK YUMUL
Left/Right = move, Up = jump, J = punch, K = Plush Toy Toss, L = Ultimate Strike.

This is a local two-player prototype.
For LAN multiplayer on phones or computers, install Python with the websockets package, then run:
python server.py
Open http://THIS-PC-LAN-IP:8764 on both devices and connect them to the same Wi-Fi or hotspot. The host selects HOST LAN ROOM and creates the shown room code. The other device selects JOIN LAN ROOM and enters the host IP and room code.
The baby-throw concept is represented as a harmless cartoon plush-toy projectile.
